# Proposal

## Why

사용자는 상담 이력·종 아이콘·즉시 푸시만 유지하고 자동 재시도와 보호 우회키를 제외하라고 결정했다. 상담의 정기 작업과 Vault URL을 제거하고 실패한 상담 푸시가 공통 worker에서 재처리되지 않도록 해야 한다.

## What Changes

- 상담 푸시는 접수 서버 요청에서 기기별 한 번만 시도하고 일시 오류도 FAILED로 종료한다. 이미 성공한 상담 접수·인앱 알림은 유지한다.
- 공통 예약 worker는 상담 이벤트를 가져가지 않는다. 신규 0043으로 상담 전용 cron만 제거하고 이번에 추가한 상담 재시도 Vault URL을 정리한다.
- 미적용 보호 우회키 제안·SQL·테스트는 즉시 푸시 정책으로 교체한다. 우회키는 생성하지 않는다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `notifications`: NOT-005 상담 즉시 단일 시도·기존 예약 재시도 분리, NOT-008 상담 이력/인앱 보존.

## Impact

PUB-001·PUB-003과 SEC-001·SEC-002·SEC-003의 공개 입력/조직 권한·기존 상담 이력을 유지한다. PLAT-003에 따라 이미 적용한 0042는 수정하지 않고 0043·비공개 백업·트랜잭션·전후 비교를 사용한다. SPEC-002·SPEC-003 연결과 실제 DB/배포 결과를 갱신한다. 원본 preview 체크아웃을 사용하며 main/운영 배포는 변경하지 않는다.
