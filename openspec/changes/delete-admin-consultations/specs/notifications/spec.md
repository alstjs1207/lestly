## MODIFIED Requirements

### Requirement: NOT-008 상담 기록과 독립적인 알림 생성

시스템 SHALL 신규 상담과 조직 공통 종 아이콘 알림·관리자 기기 푸시 대기를 함께 저장하고 유료 메시지 템플릿/관리자 전화/알림관리 활성화 여부에 의존하지 않는다. 기존 상담·발송 이력은 보존하며 신규 상담에는 알림톡·메일 발송 대기를 만들지 않는다.

#### Scenario: 푸시 미구독과 저장 실패

- **WHEN** 관리자의 푸시 구독이 없거나 상담/인앱/푸시 대기 생성 중 저장 오류가 난다
- **THEN** 미구독이어도 상담 이력·종 아이콘은 남기며, 저장 오류이면 상담·인앱·푸시 대기를 모두 롤백한다.

#### Scenario: 명시적으로 삭제한 상담의 알림

- **WHEN** 권한 있는 관리자가 상담 삭제를 확인한다
- **THEN** 해당 상담에 연결된 종 알림·푸시 이벤트/대기를 함께 삭제하고 기기 구독·다른 기록은 유지한다. 삭제 후 목록 이동 시 종 알림을 새로 조회한다.
