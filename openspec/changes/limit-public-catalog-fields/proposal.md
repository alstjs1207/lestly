# 공개 클래스 필드 최소화

## Why
공개 소개의 원본 programs/instructors 전체 조회와 공개 RLS가 내부 push_profile_id·조직 연결·비표시 가격 등의 노출을 허용한다. 페이지 투영만 고치면 직접 REST 조회가 남으므로 DB 경계도 함께 정리한다.

## What Changes
- 0044에서 고정 JSON 공개 조회 RPC를 추가하고 페이지를 전환한다.
- 0045에서 anon/PUBLIC 원본 SELECT와 공개 전체 행 RLS를 제거한다. authenticated의 자기 조직 관리자·수강생·이력 권한은 유지한다.
- 공개 JSON의 클래스/강사/커리큘럼/SNS 키를 명시한다. 기존 운영 소개 하단에서 표시하는 max_capacity는 공개 호환 필드로 유지한다.
- 기존 이력·예약·알림·종·즉시 푸시는 변경하지 않는다.

## Impact
CAT-001, SEC-002, 신규 SEC-005. PLAT-003의 기존 공유 DB·이력 보존 계약을 단계별 적용 도구에서 검증한다. PUB-001 상담 접수 계약과 서버에서 조직을 결정하는 기존 검증은 유지한다. 공유 DB 설정 자체는 정상이다. 별개로 현재 운영 main이 옛 SELECT * 공개 조회를 사용하므로 0045 전에 운영 조회 호환 패치가 필요하다. main에 preview 개편 전체를 병합하지 않는다. 승인 범위를 넘는 운영 배포는 검토 가능한 최소 패치를 준비한 뒤 별도 승인한다. 그 전에는 추가형 0044와 preview 전환만 적용할 수 있다.
