## ADDED Requirements

### Requirement: SEC-005 공개 소개의 최소 데이터 경계

시스템 SHALL 공개 클래스 소개를 고정 필드 공개 조회 함수로 제공하며, ACTIVE·공개·정확한 slug 조건을 모두 검사한다. 원본 클래스·강사 테이블에 대한 anon/PUBLIC 직접 SELECT와 로그인 외부 조직의 공개 전체 행 읽기는 허용하지 않는다. 소개에 쓰는 이름·설명·이미지·커리큘럼·강사 경력·공개 SNS와 상담 대상 program_id만 반환하며, 기존 운영 소개에서 공개하는 정원은 호환을 위해 허용한다. 조직 ID·강사 내부 ID·push_profile_id·가격·운영 시간 목록·작성/변경 시각은 공개 계약에서 제외한다. 자기 조직 관리자·수강생의 기존 권한과 예약·상담 이력은 유지한다.

#### Scenario: 익명 페이지와 직접 DB 조회

- **WHEN** 비회원이 공개 클래스 소개나 원본 테이블·내부 컬럼을 조회한다
- **THEN** 소개 함수는 명시된 공개 필드만 반환하고 원본 테이블/내부 컬럼 읽기는 차단한다. 커리큘럼·SNS의 비공개 추가 키도 반환하지 않는다.

#### Scenario: 로그인한 외부 조직 사용자

- **WHEN** 조직 B 사용자가 조직 A의 공개 소개와 원본 클래스·강사 테이블을 조회한다
- **THEN** 공개 함수에서는 소개만 제공하고 자기 조직 멤버십·예약 이력 권한이 없는 원본 행은 노출하지 않는다.

#### Scenario: 기존 조직 기능과 공개 상태

- **WHEN** 자기 조직 관리자·수강생이 클래스 관리·선택을 사용하거나 외부 사용자가 비공개·DRAFT·ARCHIVED·없는 slug를 조회한다
- **THEN** 기존 조직 기능은 유지하고 공개 불가 클래스는 소개 함수에서도 반환하지 않는다. 강사 미지정 공개 클래스는 강사 없이 소개를 제공한다.

#### Scenario: 단계별 배포와 기존 데이터

- **WHEN** 최소 공개 조회와 원본 읽기 권한 회수를 적용한다
- **THEN** 기존 공개 페이지가 새 조회 계약을 사용하도록 먼저 전환하고 원본 클래스·강사·예약·상담·알림 데이터와 관련 없는 권한·cron을 변경하지 않는다.
