# Proposal

## Why

클래스 폼이 비공개 수업에도 슬러그를 요구하고, 새 강사를 등록하려면 입력 중인 클래스를 떠나야 한다. 외부 공개 여부에 맞춰 검증하고 입력을 유지하면서 담당 강사를 추가할 수 있어야 한다.

## What Changes

- 비공개 클래스는 슬러그 없이 저장하고 외부 공개를 켠 경우에만 슬러그를 필수로 요구한다. 공개 토글을 바꿔도 입력한 슬러그는 유지한다.
- 서버와 신규 DB 제약으로 공개 슬러그 누락을 막는다. 기존 전역 고유 제약·기존 링크·대소문자 정책은 유지한다.
- 담당 강사를 선택으로 유지하고 미지정으로 되돌릴 수 있게 한다.
- 클래스 생성·수정 폼에서 이름·소개를 입력하는 강사 추가 모달을 제공한다. 성공하면 현재 조직 강사를 생성·자동 선택하고 클래스의 입력·커리큘럼·선택 파일을 유지한다. 취소·실패는 클래스 저장이나 페이지 이동을 일으키지 않는다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `catalog`: CAT-001 공개 슬러그 조건, CAT-004 강사 선택 및 입력을 보존하는 모달 생성.

## Impact

클래스 폼·공통 입력 검증·기존 강사 생성 API의 모달 응답 모드, 신규 0041 migration, 단위·격리 SQL·브라우저 회귀, policy-map/source-index에 영향을 준다. SEC-001·SEC-003의 조직 관리자·동일 출처 검증은 기존 경로를 재사용한다. PLAT-003에 따라 기존 데이터 변경 없이 새 migration만 준비하며 실제 DB 적용·커밋·푸시·배포는 이번 요청에서 수행하지 않는다. SPEC-002·SPEC-003에 따라 새 파일과 검증 근거를 등록한다.
