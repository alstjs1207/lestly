# Preview release

사용자 요청으로 상담은 저장된 이력·종 아이콘·기기별 즉시 푸시만 사용한다. CAPTCHA·상담 자동 재시도·Vercel 보호 우회키는 사용하지 않는다. 공개 API의 입력/횟수/중복 방지·관리자 조직 권한은 유지한다.

0042는 이미 적용한 이력이므로 수정하지 않는다. 0043으로 상담 전용 cron만 제거하고, 적용 스크립트에서 이번에 추가한 Vault 상담 재시도 URL만 정확한 값 확인 후 삭제한다. 다른 job과 기존 상담/예약/발송 데이터는 보존한다. 결과와 백업 검증은 verification.md를 참조한다.

preview 전용 HMAC 비밀과 기존 VAPID 키는 즉시 푸시에 필요하므로 유지한다. 기존 예약 worker와 CRON_SECRET은 다른 예약 알림의 기존 기능이므로 유지한다. 즉시 푸시 전송이 실패해도 상담 이력·종 아이콘은 남고 자동 재시도하지 않는다.

preview 프로젝트의 기존 Vercel 로그인 보호는 유지한다. 이 보호 때문에 비로그인 외부 curl은 SSO 응답을 받을 수 있으므로 기존 로그인 브라우저에서 화면/API의 입력 오류·관리자 인증을 확인한다. Vercel 설정을 완화하거나 우회키를 생성하지 않는다. main 브랜치/운영 배포는 변경하지 않는다.
