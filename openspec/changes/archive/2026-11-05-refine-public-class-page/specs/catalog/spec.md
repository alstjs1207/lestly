## ADDED Requirements

### Requirement: CAT-005 공개 소개 구성과 상담 진입

시스템 SHALL 기존 커버·설명·커리큘럼·강사 정보를 등록 상태에 따라 표시하고, 하단 고정 영역은 정원·일정 대신 상담 버튼으로 제공한다. 상담 버튼은 기존 단일 신청 폼을 열며 보안 설정이 없을 때 비활성 준비 상태를 표시한다. 공개 페이지는 다음 예약 일정을 조회하지 않는다. 커버 없는 상단은 축소하고 커리큘럼·강사 중 한 영역만 있으면 전체 폭을 사용한다. 수업 시간은 회당 시간으로, 총 회차는 등록된 소개 정보로 표시한다.

관리자는 기존 커버를 모바일/PC 비율로 미리 보고, ACTIVE·공개·slug 조건을 충족할 때만 활성 공개 링크를 제공받는다. 기존 slug·등록 내용·예약 데이터는 변경하지 않는다. 공유 메타는 기존 클래스명·설명·안전한 HTTP(S) 커버와 query 없는 해당 페이지 URL에서 구성한다.

#### Scenario: 하단에서 상담 시작

- **WHEN** 외부 사용자가 공개 클래스 소개를 스크롤하고 하단 상담 버튼을 선택한다
- **THEN** 정원·일정은 하단에 표시하지 않고 기존 상담 폼 하나를 열며 기존 입력 검증·요청 제한·즉시 푸시 계약을 유지한다. 보안 설정이 없으면 상담 버튼은 비활성이다.

#### Scenario: 선택 콘텐츠와 화면 크기

- **WHEN** 커버가 없거나 커리큘럼·강사 중 하나만 등록된 클래스를 모바일/PC에서 표시한다
- **THEN** 상단 빈 공간을 줄이고 단독 콘텐츠는 전체 폭으로 표시한다. 두 콘텐츠가 모두 있으면 PC에서는 두 칸으로 표시하며 등록된 회차·강사 소개·SNS·장소를 유지한다.

#### Scenario: 커버와 공유 미리보기

- **WHEN** 관리자가 기존 커버를 등록하고 제목·부제목을 입력하거나 외부 사용자가 공개 페이지를 공유한다
- **THEN** 관리자는 모바일/PC 잘림 미리보기를 보고 공유 페이지는 서버 렌더링한 제목·설명·URL 및 HTTP(S) 커버 메타를 제공한다. 커버가 없으면 이미지 메타를 생략한다.

#### Scenario: 공개 상태와 저장된 주소

- **WHEN** 관리자가 공개/비공개 또는 ACTIVE/DRAFT/ARCHIVED 클래스의 상세를 확인한다
- **THEN** ACTIVE·공개·slug 조건을 모두 만족할 때만 공개 URL을 링크로 제공하고 나머지는 주소를 보존한 텍스트와 공개 조건 안내를 표시한다.
