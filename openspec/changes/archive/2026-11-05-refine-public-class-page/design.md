# Design

공개 페이지는 기존 클래스 데이터만 사용한다. ClassFooter는 consultEnabled와 onConsult만 받아 상담 진입을 제공하고, 폼은 ClassDetail의 기존 단일 Dialog를 공유한다. 모달을 footer보다 높은 레이어에 두고, iOS safe-area 및 본문 하단 여백·작은 화면 모달 스크롤을 처리한다.

커버는 기존 중앙 object-cover 배치를 유지한다. 관리자 미리보기는 모바일 390:300, PC 1200:400 비율에서 잘림을 보여주고 현재 제목/부제목을 반영한다. 크롭 위치·브랜드·갤러리 등 새 DB 필드는 추가하지 않는다.

공개 링크는 ACTIVE + is_public + slug일 때만 활성화한다. 비공개·초안·보관 상태는 저장된 slug를 유지한 비활성 텍스트와 안내를 표시한다. 등록·수정의 기존 공개 검증은 유지한다.

공유 URL은 요청 origin과 저장된 slug에서 구성하며 query를 제외한다. 메타 설명은 부제목·상세 설명을 조합하고 비어 있으면 기본 문구를 사용하며 공백 정리 후 160자까지 사용한다. 커버는 HTTP(S)일 때만 공유 이미지로 포함한다. 미등록·비공개 콘텐츠를 위한 별도 공개 API는 만들지 않는다.
