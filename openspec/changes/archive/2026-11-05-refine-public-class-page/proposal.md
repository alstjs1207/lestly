# 공개 클래스 소개와 상담 진입 개선

## Why
기존 커버·커리큘럼·강사 입력 기능을 유지하면서 공개 페이지의 상담 진입과 비어 있는 콘텐츠 배치를 개선한다. 사용자는 하단 정원·일정을 제거하고 상담 버튼으로 대체하도록 요청했다.

## What Changes
- 하단 고정 상담 버튼 하나에서 기존 상담 Dialog를 연다. 정원·일정 노출과 공개 페이지의 다음 일정 조회를 제거한다.
- 커버 없는 상단을 축소하고 커리큘럼·강사 중 하나만 있으면 전체 폭으로 표시한다. 회당 시간·총 회차 의미를 유지하고 강사 사진을 반응형으로 줄인다.
- 기존 커버의 모바일/PC 잘림 미리보기와 실제 공개 조건 안내를 추가한다.
- 기존 제목·설명·커버 기반 OG/Twitter/canonical 메타를 서버에서 제공한다.

## Impact
CAT-001, CAT-004의 기존 입력·공개 권한을 보존하고 CAT-005를 추가한다. PUB-001의 기존 상담 검증·요청 제한·중복 방지·즉시 푸시 동작은 변경하지 않는다. DB 변경·운영 main 변경은 없다. preview에서 구현·검증·배포한다.
