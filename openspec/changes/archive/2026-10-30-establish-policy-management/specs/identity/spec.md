# Spec Delta

## Purpose

관리자와 수강생의 로그인, 초대 연결, 계정 변경 경계를 정의한다. 연락용 이메일과 인증 계정을 구분하고 기존 수강생 프로필을 연결하는 현재 동작을 보존한다.

## ADDED Requirements

### Requirement: AUTH-001 검증된 계정만 세션 사용

시스템 SHALL 인증 토큰을 검증하고 현재 계정 접근 허용 여부를 확인한 뒤 보호된 기능을 제공한다. 차단된 계정은 로컬 세션을 종료하고 접근을 거절한다.

#### Scenario: 차단된 계정의 기존 토큰

- **WHEN** 탈퇴 차단된 사용자가 유효한 형태의 기존 토큰으로 보호된 화면을 요청한다
- **THEN** 계정 접근을 거절하고 기존 토큰만으로 사용을 허용하지 않는다.

### Requirement: AUTH-002 관리자 가입 단계

시스템 SHALL 관리자 가입을 인증, 프로필·약관 설정, 조직 생성과 ADMIN 멤버십 연결 순서로 제공한다. 조직 설정 도중 후속 저장이 실패하면 앞서 생성한 조직·멤버십의 보상 삭제를 시도한다.

#### Scenario: 이미 소속이 있는 관리자

- **WHEN** NORMAL ADMIN 멤버십이 있는 사용자가 조직 설정을 요청한다
- **THEN** 기존 관리자 화면으로 이동하고 같은 가입 단계에서 새 조직을 중복 생성하지 않는다.

#### Scenario: 프로필 설정 오류

- **WHEN** 필수 약관·이름·8자 이상 비밀번호 또는 비밀번호 확인이 유효하지 않다
- **THEN** 오류를 표시하고 조직 생성 단계로 진행하지 않는다.

### Requirement: AUTH-003 단회성 초대 연결

시스템 SHALL NORMAL 상태이며 인증 계정이 없는 수강생에게 7일 유효 초대 링크를 발급하고 이전 미사용 링크를 폐기한다. 토큰은 해시로 저장하고 사용·만료·폐기된 링크의 계정 연결을 거절한다.

#### Scenario: 재발급

- **WHEN** 관리자가 아직 계정 연결되지 않은 NORMAL 수강생의 초대를 재발급한다
- **THEN** 이전 링크는 폐기되고 새 원문 토큰은 발급 응답으로만 제공된다.

#### Scenario: 기존 학생 연결

- **WHEN** 초대받은 사용자가 소셜 인증을 완료하고 유효 링크를 사용한다
- **THEN** 기존 수강생 프로필에 인증 계정을 연결하고 예약·수강 이력을 보존한다.

### Requirement: AUTH-004 이메일 선택과 소셜 연결

시스템 SHALL 수강생 연락용 이메일 없이 등록·초대·카카오 로그인을 지원한다. 카카오 로그인은 프로필 이름·이미지 동의를 요청하며 검증되지 않은 임의 메타데이터로 연락 이메일을 덮어쓰지 않는다. 계정의 연결·해제 제공자는 github와 kakao다.

#### Scenario: 이메일 없는 수강생

- **WHEN** 이메일 없는 기존 수강생이 초대 링크로 카카오 계정을 연결한다
- **THEN** 이메일 필수 동의 때문에 기존 프로필 연결을 차단하지 않는다.

### Requirement: AUTH-005 자기 계정 변경과 삭제

시스템 SHALL 인증한 사용자의 프로필·이메일·비밀번호·소셜 연결을 본인 계정에 한해 변경한다. 아바타는 허용 이미지 형식·실제 파일 시그니처·1MB 제한을 검증한다. 계정 삭제는 수강 종료·탈퇴와 별개이며 인증 계정 삭제 성공 후 로컬 세션을 종료한다.

#### Scenario: 허위 이미지 업로드

- **WHEN** 인증한 사용자가 이미지로 가장한 파일을 아바타로 제출한다
- **THEN** 저장 전 파일 검증에서 거절한다.

#### Scenario: 계정 삭제

- **WHEN** 본인이 DELETE 요청으로 계정 삭제를 실행하고 인증 계정 삭제가 성공한다
- **THEN** 아바타 정리를 시도하고 로컬 세션을 종료한다. 관리자 수강생 탈퇴로 이를 대체하지 않는다.
