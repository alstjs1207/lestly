# 관리자 상담 삭제

## Why
사용자가 관리자 상담 삭제 기능을 요청했다. 자기 조직의 상담만 삭제하도록 서버와 DB 권한을 함께 제한하고 연결된 알림을 정리한다.

## What Changes
상담 상세에 확인 Dialog와 삭제 action을 추가한다. 삭제는 POST·동일 출처·NORMAL ADMIN·자기 조직·CONSULT_REQUEST·명시적 확인 조건을 검사한다. 0046은 상담 DELETE RLS만 추가하고 기존 신청 UUID 기록은 삭제 후에도 원래 만료까지 남도록 FK를 SET NULL로 바꾼다. 삭제 후 목록으로 돌아가고 종 알림을 새로 조회한다.

## Impact
CAT-005의 공개 소개/상담 진입을 유지하고, PUB-001/PUB-003의 기존 상담 계약과 신규 PUB-004, NOT-004/NOT-008의 종·푸시, SEC-001/SEC-002/SEC-003 권한을 유지한다. PLAT-003에 따라 기존 상담·예약·프로필·발송 기록은 마이그레이션에서 변경하지 않는다. 사용자 확인 삭제에 해당하는 한 건과 연결 종/푸시 데이터만 이후 삭제할 수 있다. 기존 preview 검증 후 main 병합·운영 배포 흐름을 따른다.
