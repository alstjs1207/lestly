# Design

관리자 메뉴와 해당 폼/상세 영역만 제거한다. 기능 코드를 삭제하거나 DB 상태를 비공개로 일괄 전환하지 않는다. 클래스 form은 기존 slug/is_public을 hidden input으로 전송하고 신규 기본값은 빈 slug/비공개로 유지한다. 기존 서버 입력 검증과 RLS는 동일하게 적용된다.

종 아이콘에서 상담 전체 보기 링크를 제거하고 상담 알림 항목은 링크 없이 읽음 동작만 유지한다. 일반 알림 이력 링크와 일반 알림 항목은 유지한다. 공개 링크·상담 접수·기기 푸시의 기존 목적지와 직접 관리자 경로는 유지한다.

기존 built-route SSR에서 생성/수정 hidden 값과 상세의 공개 카드 미노출·운영정보 유지를 확인하고 전체 로컬 검증을 수행한다. 실제 DB 쓰기·고객 상담 삭제·외부 발송은 하지 않는다.
