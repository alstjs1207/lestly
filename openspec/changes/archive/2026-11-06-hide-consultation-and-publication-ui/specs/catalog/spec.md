## MODIFIED Requirements

### Requirement: CAT-001 상태와 공개 소개

시스템 SHALL 클래스를 DRAFT/ACTIVE/ARCHIVED로 관리하고 공개 소개는 ACTIVE이면서 is_public인 slug에만 제공한다. 수강생의 신규 선택은 활성 클래스에 한한다. 클래스 보관은 기존 예약 취소를 뜻하지 않는다. 신규 저장·수정에서 외부 공개가 켜졌을 때만 공백이 아닌 슬러그를 요구하고 비공개는 슬러그 없이 허용한다. 기존 전역 슬러그 고유 제약과 링크·대소문자 정책은 유지하며 공개 해제만으로 기존 슬러그를 삭제하지 않는다. 공개 소개는 SEC-005의 최소 필드 조회 계약을 사용한다. 현재 관리자 생성·수정 화면은 공개 여부·슬러그 조작 UI를 임시 숨기며 기존 값은 hidden form으로 보존한다. 신규 클래스 기본값은 비공개/빈 슬러그이며 공개 API·기존 공개 URL은 유지한다.

#### Scenario: 보관된 클래스

- **WHEN** 예약이 있는 클래스를 ARCHIVED로 변경한다
- **THEN** 새 선택에서 제외하되 기존 예약과 안내는 유지한다.

#### Scenario: 비공개 소개 요청

- **WHEN** 비공개 또는 비활성 클래스의 공개 slug를 요청한다
- **THEN** 일반 외부 사용자에게 소개 내용을 노출하지 않는다.

#### Scenario: 비공개 클래스와 공개 전환

- **WHEN** 관리자가 슬러그 없는 비공개 클래스를 생성하거나 수정하거나 기존 서버 API로 공개를 전환한다
- **THEN** 강사 미지정 여부와 무관하게 다른 조건이 유효하면 저장한다. 외부 공개를 켜면 슬러그를 요구하고 빈 값은 서버·DB에서 거절한다. 관리자 화면의 공개 전환 UI는 임시 숨김 상태다.

#### Scenario: 공개 설정 왕복과 중복 주소

- **WHEN** 관리자가 슬러그를 입력한 뒤 공개를 껐다 켜거나 이미 사용 중인 슬러그를 저장한다
- **THEN** 토글만으로 입력을 지우지 않고 기존 전역 고유 제약으로 동일한 슬러그의 중복 저장은 거절한다.

### Requirement: CAT-005 공개 소개 구성과 상담 진입

시스템 SHALL 기존 커버·설명·커리큘럼·강사 정보를 등록 상태에 따라 표시하고, 하단 고정 영역은 정원·일정 대신 상담 버튼으로 제공한다. 상담 버튼은 기존 단일 신청 폼을 열며 보안 설정이 없을 때 비활성 준비 상태를 표시한다. 공개 페이지는 다음 예약 일정을 조회하지 않는다. 커버 없는 상단은 축소하고 커리큘럼·강사 중 한 영역만 있으면 전체 폭을 사용한다. 수업 시간은 회당 시간으로, 총 회차는 등록된 소개 정보로 표시한다.

관리자는 기존 커버를 모바일/PC 비율로 미리 본다. 클래스 상세의 공개 설정 카드·공개 링크와 생성/수정의 공개 여부·슬러그 UI는 임시 숨긴다. 기존 slug·등록 내용·예약 데이터는 변경하지 않는다. 공유 메타는 기존 클래스명·설명·안전한 HTTP(S) 커버와 query 없는 해당 페이지 URL에서 구성한다.

#### Scenario: 하단에서 상담 시작

- **WHEN** 외부 사용자가 공개 클래스 소개를 스크롤하고 하단 상담 버튼을 선택한다
- **THEN** 정원·일정은 하단에 표시하지 않고 기존 상담 폼 하나를 열며 기존 입력 검증·요청 제한·즉시 푸시 계약을 유지한다. 보안 설정이 없으면 상담 버튼은 비활성이다.

#### Scenario: 선택 콘텐츠와 화면 크기

- **WHEN** 커버가 없거나 커리큘럼·강사 중 하나만 등록된 클래스를 모바일/PC에서 표시한다
- **THEN** 상단 빈 공간을 줄이고 단독 콘텐츠는 전체 폭으로 표시한다. 두 콘텐츠가 모두 있으면 PC에서는 두 칸으로 표시하며 등록된 회차·강사 소개·SNS·장소를 유지한다.

#### Scenario: 커버와 공유 미리보기

- **WHEN** 관리자가 기존 커버를 등록하고 제목·부제목을 입력하거나 외부 사용자가 공개 페이지를 공유한다
- **THEN** 관리자는 모바일/PC 잘림 미리보기를 보고 공유 페이지는 서버 렌더링한 제목·설명·URL 및 HTTP(S) 커버 메타를 제공한다. 커버가 없으면 이미지 메타를 생략한다.

#### Scenario: 공개 상태와 저장된 주소

- **WHEN** 관리자가 공개/비공개 또는 ACTIVE/DRAFT/ARCHIVED 클래스의 상세를 확인한다
- **THEN** 공개 설정 카드·공개 링크를 표시하지 않고 클래스 운영 정보는 유지한다. 생성/수정에서 공개 여부·슬러그 UI 없이 기존 값을 hidden form으로 보존하며 신규 클래스는 비공개/빈 슬러그가 기본이다. 기존 외부 링크와 공개 접수는 유지한다.
