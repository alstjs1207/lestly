## MODIFIED Requirements

### Requirement: PUB-003 상담 관리와 기존 이력

시스템 SHALL NORMAL ADMIN에게 자기 조직의 상담만 별도 목록·상세로 제공하고 기존 이름·전화·문의·상태·결과·메모·완료 이력을 보존한다. 목록은 이름·전화·내용 요약을 표시하고 상세로 연결한다. 유효한 전화는 전화 연결을 제공한다. 수정은 상태·결과·최대 5,000자 메모로 제한하고 완료 기록은 처리자/시각으로 관리한다. 현재 관리자 사이드바의 상담관리와 종 아이콘의 상담 목록/상세 진입 UI는 임시 숨긴다. 기존 직접 경로와 인증·조직 권한, 상담 데이터와 접수는 유지한다.

#### Scenario: 다른 조직 조회와 수정

- **WHEN** 조직 A 관리자 또는 학생이 조직 B의 상담 ID로 상세/수정을 요청한다
- **THEN** 상담을 노출하거나 수정하지 않으며 원본 전화·문의·조직·작성 시각 변경도 허용하지 않는다.

#### Scenario: 목록과 상세

- **WHEN** 관리자가 상담관리 목록에서 신청 건 또는 유효한 전화번호를 선택한다
- **THEN** 신청 건은 전문/처리 상세로 이동하고 전화번호는 상세 이동 없이 통화 연결을 요청한다. 알림관리 목록에는 상담 접수 건을 섞지 않는다.

#### Scenario: 완료와 대기 복귀

- **WHEN** 관리자가 상담을 완료하거나 다시 대기로 변경한다
- **THEN** 완료 시각·담당자를 기록하거나 해제하고 기존 문의 내용과 알림 읽음 상태는 유지한다.

#### Scenario: 기존 상담 보존

- **WHEN** 새 상담 기능의 DB 변경을 적용한다
- **THEN** 기존 상담/예약/프로필/발송 이력을 다시 쓰거나 삭제하지 않고 과거 상담에 새 푸시를 재생하지 않는다.

#### Scenario: 상담관리 진입 UI 임시 숨김

- **WHEN** 관리자가 사이드바나 종 아이콘을 확인한다
- **THEN** 상담관리 메뉴·상담 전체 보기·상담 상세 링크는 표시하지 않는다. 상담 알림 텍스트와 읽음, 직접 경로의 기존 상담 기능·권한과 이력은 유지한다.
