# 관리자 상담/공개 설정 UI 임시 숨김

## Why
사용자가 상담관리와 클래스 공개 설정·공개 슬러그 기능을 일단 숨기도록 요청했다. 저장된 공개 상태와 주소를 보존하면서 관리자 화면의 관련 진입점과 조작 영역을 정리한다.

## What Changes
상담관리 사이드바·종 아이콘의 전체 보기/상세 진입 링크와 클래스 생성·수정의 공개 조작 UI 및 상세 공개 설정 카드를 숨긴다. 상담 종 알림 텍스트/읽음은 유지한다. 공개 여부와 슬러그는 hidden form 값으로 유지해 일반 클래스 수정이 기존 공개 페이지를 닫거나 주소를 지우지 않게 한다.

## Impact
CAT-001/CAT-005와 PUB-003, NOT-004의 화면 노출 정책만 변경한다. CAT-002/CAT-004의 예약/강사·커버 편집, PUB-001의 공개 상담 접수, PUB-004의 직접 경로 삭제 권한, NOT-005/NOT-008의 기존 푸시·알림 생성과 이력은 유지한다. DB/환경변수/공개 라우트/관리자 권한/API는 변경하지 않는다. UI 숨김을 접근 차단으로 간주하지 않는다. PLAT-003의 로컬 검증 후 기존 preview 배포 흐름을 따른다.

공유 SSR 파일의 STU-004 수강 기간/종료 접근과 SEC-005 공개 최소 조회 시나리오는 그대로 실행해 보존을 확인한다. SPEC-001에 따라 명세와 소스/검증 연결만 함께 갱신하며 이 영역의 제품 정책을 변경하지 않는다.
