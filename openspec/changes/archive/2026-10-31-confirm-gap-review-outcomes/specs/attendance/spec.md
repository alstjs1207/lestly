# Spec Delta

## MODIFIED Requirements

### Requirement: ATT-003 기존 출석과 결석 복원

시스템 SHALL 정원 축소 뒤에도 이미 활성인 기존 예약의 출석 확인을 허용한다. ABSENT에서 복원할 때는 정원과 학생 중복을 재검사한다. 클래스 보관·수강 종료·탈퇴 후에도 시작된 수업의 출결 정정을 허용한다. 진행 중 결석을 출석으로 정정하면 해당 예약을 유효하게 복원하되 학생의 종료·탈퇴 상태와 다른 취소된 예정 예약은 유지한다.

#### Scenario: 정원 축소 후 확인

- **WHEN** 기존 활성 예약 수가 새 정원보다 많지만 기존 예약의 출석만 확인한다
- **THEN** 새 점유 생성으로 간주해 거절하지 않는다.

#### Scenario: 자리 재사용 후 복원

- **WHEN** 결석 취소로 빈 자리가 다른 학생 예약으로 찬 뒤 결석을 복원한다
- **THEN** 정원을 재검사하고 초과하면 복원을 거절한다.

#### Scenario: 종료·탈퇴 후 진행 중 결석을 출석으로 정정

- **WHEN** 관리자가 진행 중 수업을 결석 처리하고 학생을 수강 종료 또는 탈퇴시킨 뒤, 정원·중복 조건을 충족하는 해당 회차를 출석으로 정정한다
- **THEN** 해당 회차의 취소 상태를 해제하고 출결 이력을 보존한다. 학생의 종료·탈퇴 상태와 상태 변경 때 취소한 다른 예정 예약은 그대로 유지한다.
