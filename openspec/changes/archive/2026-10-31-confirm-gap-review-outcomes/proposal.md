# Proposal

## Why

사용자가 2026-10-31 GAP 검토를 마무리하며 현재 동작의 허용 범위와 후속 정리 대상을 확정했다. 초기 미확정 표시가 같은 질문·수정 제안을 반복하게 만들지 않도록 현재 명세와 목록에 결정을 반영한다.

## What Changes

- GAP-001을 현재 로직 정상으로 확정하고 ATT-003에 종료·탈퇴 후 진행 중 결석 복원을 명시한다. 학생 상태를 자동 복귀시키지 않고 정원·중복 검사를 유지한다.
- GAP-002는 조직+전화번호의 고유 범위가 이미 분리되어 있음을 적고, 한 계정이 두 조직에 포함되는 경우의 접근·연결·화면 문제 확인 항목으로 남긴다.
- GAP-003/004는 현재 기능 없음으로 유지한다. 구현 요청으로 해석하지 않는다.
- GAP-005 이후는 개별 주제와 근거를 보존하면서 후속 정리로 보류한다.
- 이미 재현한 6개 출결 조합의 테스트 결과 분류를 정책 질문에서 확인된 정상 동작으로 바꾼다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `attendance`: ATT-003의 미확정 범위를 사용자가 허용한 현재 동작으로 확정한다. STU-005의 학생 상태·다른 취소 예약 보존과 함께 해석한다.

## Impact

현재 정책 문서·GAP 상태와 SQL 회귀의 결과 메타데이터만 변경한다. 앱·DB 마이그레이션·실제 데이터·권한·발송·원격 저장소는 변경하지 않는다. 복수 조직 개선이나 보류 기능 수정은 수행하지 않는다.
