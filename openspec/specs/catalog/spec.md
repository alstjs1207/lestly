# catalog Specification

## Purpose
조직별 클래스·강사 관리와 외부에 공개하는 소개 정보를 정의한다. 클래스의 실제 시간·정원 계약과 홍보 정보인 총 회차를 구분하고 기존 예약을 보존한다.

## Requirements

### Requirement: CAT-001 상태와 공개 소개

시스템 SHALL 클래스를 DRAFT/ACTIVE/ARCHIVED로 관리하고 공개 소개는 ACTIVE이면서 is_public인 slug에만 제공한다. 수강생의 신규 선택은 활성 클래스에 한한다. 클래스 보관은 기존 예약 취소를 뜻하지 않는다. 신규 저장·수정에서 외부 공개가 켜졌을 때만 공백이 아닌 슬러그를 요구하고 비공개는 슬러그 없이 허용한다. 기존 전역 슬러그 고유 제약과 링크·대소문자 정책은 유지하며 공개 해제만으로 기존 슬러그를 삭제하지 않는다.

#### Scenario: 보관된 클래스

- **WHEN** 예약이 있는 클래스를 ARCHIVED로 변경한다
- **THEN** 새 선택에서 제외하되 기존 예약과 안내는 유지한다.

#### Scenario: 비공개 소개 요청

- **WHEN** 비공개 또는 비활성 클래스의 공개 slug를 요청한다
- **THEN** 일반 외부 사용자에게 소개 내용을 노출하지 않는다.

#### Scenario: 비공개 클래스와 공개 전환

- **WHEN** 관리자가 슬러그 없는 비공개 클래스를 생성하거나 수정한다
- **THEN** 강사 미지정 여부와 무관하게 다른 조건이 유효하면 저장한다. 외부 공개를 켜면 슬러그를 요구하고 빈 값은 화면·서버·DB에서 거절한다.

#### Scenario: 공개 설정 왕복과 중복 주소

- **WHEN** 관리자가 슬러그를 입력한 뒤 공개를 껐다 켜거나 이미 사용 중인 슬러그를 저장한다
- **THEN** 토글만으로 입력을 지우지 않고 기존 전역 고유 제약으로 동일한 슬러그의 중복 저장은 거절한다.

### Requirement: CAT-002 클래스 시간·정원과 기본값

시스템 SHALL 클래스별 기본 길이·허용 길이·정원을 실제 예약 규칙으로 사용한다. 길이는 1~1440분, 허용 목록은 1~48개 고유 값이며 기본 길이를 포함한다. 정원은 1~100명이다. 조직 기본값은 생성 시 한 번 복사하고 이후 기존 클래스에 전파하지 않는다.

#### Scenario: 조직 기본값 변경

- **WHEN** 기존 클래스가 있는 조직에서 새 클래스 기본 시간·정원을 바꾼다
- **THEN** 기존 클래스·예약은 유지하고 이후 새 클래스에 바뀐 기본값을 채운다.

### Requirement: CAT-003 예약 연결과 클래스 삭제

시스템 SHALL 모든 새 예약에 클래스 연결을 요구하고 예약 행이 존재하는 클래스 삭제를 거절한다. 기존 예약 길이가 새 허용 목록에 없어도 같은 클래스의 동일 길이 이동은 보존하며 클래스 변경은 대상 규칙을 적용한다.

#### Scenario: 기존 길이 보존

- **WHEN** 기존 예약 길이가 현재 허용 목록에서 빠졌고 같은 클래스로 시간을 이동한다
- **THEN** 기존 길이를 유지할 수 있다.

#### Scenario: 예약 있는 클래스 삭제

- **WHEN** 출결 취소를 포함해 연결 예약 행이 남아 있는 클래스를 삭제한다
- **THEN** 삭제를 거절하고 보관 사용을 안내한다.

### Requirement: CAT-004 강사와 소개 입력

시스템 SHALL 담당 강사를 선택 사항으로 유지하고 연결할 때 같은 조직 강사만 허용한다. 클래스 생성·수정 폼의 강사 추가 모달에서 이름과 선택 소개를 저장하면 새 강사를 자동 선택한다. 모달 성공·취소·실패와 재시도에서 클래스 입력·커리큘럼·선택 파일을 보존하며 클래스 저장이나 페이지 이동을 유발하지 않는다. 기존 강사 생성 화면의 완료 이동은 유지한다. 소개 이미지의 형식·시그니처·5MB 제한과 외부 링크의 HTTP(S) 형식을 검증한다. 온라인 수업은 주소 지도 대신 접속 방법 문의 안내를 제공한다. 총 회차는 소개 정보이며 소진 제한을 구현한 것으로 안내하지 않는다.

#### Scenario: 허위 업로드

- **WHEN** 관리자가 허용되지 않은 이미지나 5MB 초과 파일을 강사·클래스에 제출한다
- **THEN** 업로드 전에 거절하고 기존 이미지를 유지한다.

#### Scenario: 온라인 수업

- **WHEN** location_type이 online인 수업을 표시한다
- **THEN** 온라인 안내를 표시하고 오프라인 지도 링크를 표시하지 않는다.

#### Scenario: 강사 없이 저장과 미지정 복귀

- **WHEN** 관리자가 강사를 선택하지 않거나 선택한 강사를 미지정으로 바꾸고 클래스를 저장한다
- **THEN** 다른 필수 조건이 유효하면 강사 연결 없이 저장하고 기존 예약 가능 정책은 유지한다.

#### Scenario: 입력 중 강사 추가

- **WHEN** 클래스명·소개·공개 설정·수업 시간·커리큘럼·커버 파일을 입력한 관리자가 모달에서 새 강사를 생성한다
- **THEN** 권한 조직에 강사 한 명을 생성하고 선택 목록에 추가·자동 선택한다. 클래스 폼은 이동·제출·초기화하지 않는다.

#### Scenario: 모달 실패와 취소

- **WHEN** 모달 입력 검증이나 저장이 실패하거나 사용자가 취소한다
- **THEN** 클래스 입력과 기존 강사 선택을 유지한다. 실패 시 모달에서 오류를 표시하고 입력을 유지해 재시도하며 저장 중 중복 제출을 막는다.
