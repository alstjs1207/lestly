# payments Specification

## Purpose
현재 포함된 결제 예제를 실제 수강료 결제와 분리한다. 운영 환경에서 데모 결제를 비활성화하고 데모 실행 시 금액·사용자·주문 서명과 응답을 확인하는 경계를 정의한다.

## Requirements

### Requirement: PAY-001 운영 결제 데모 비활성

시스템 SHALL production에서 결제 데모 checkout·success를 404로 차단한다. 비운영 환경에서도 테스트 secret 형식이 유효할 때만 데모를 허용한다. 실제 수강료 청구·환불·회차 소진 기능을 제공한다고 간주하지 않는다.

#### Scenario: 운영 요청

- **WHEN** 테스트 키가 있어도 production에서 데모 결제를 요청한다
- **THEN** 404로 거절하고 외부 결제 승인을 호출하지 않는다.

### Requirement: PAY-002 데모 주문 검증과 본인 내역

시스템 SHALL 인증한 본인의 서명된 데모 주문과 고정 10000원 금액을 확인하고 발급 2시간 이내 주문만 검증한다. 외부 승인 응답의 주문·결제키·금액·DONE을 대조하고 저장 실패는 오류로 처리한다. 결제 내역은 본인 범위로 제공한다.

#### Scenario: 다른 사용자의 주문

- **WHEN** 인증한 사용자가 다른 사용자의 유효한 데모 주문을 제출한다
- **THEN** 주문 서명 검증에서 거절하고 승인하지 않는다.
