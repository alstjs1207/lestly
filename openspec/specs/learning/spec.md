# learning Specification

## Purpose
수강생 본인의 출석 확인된 종료 수업에 기반한 학습 시간·일정·히트맵을 정의한다. 실제 출석 데이터와 브라우저 로컬 회고, 오래된 샘플 화면을 구분한다.

## Requirements

### Requirement: LEARN-001 출석 기반 집계

시스템 SHALL PRESENT이며 종료된 유효 수업만 학습 시간에 포함하고 실제 시작·종료 차이를 사용한다. 예정·미확인·결석·취소 수업을 완료 학습으로 세지 않으며 시간 조회 대체 경로도 같은 조건을 유지한다.

#### Scenario: 미확인 종료 수업

- **WHEN** 종료 시각이 지났지만 출결이 PENDING이다
- **THEN** 완료 학습 시간과 참여 횟수에 포함하지 않는다.

### Requirement: LEARN-002 히트맵과 일정 표시

시스템 SHALL KST 수업 시작일별 출석 확인된 종료 수업의 참여 횟수로 히트맵을 표시하고 실제 시간을 분 단위로 안내한다. 날짜 이동·모바일 일정·주간/월간 조회에서도 취소된 예약을 일반 유효 일정에서 제외한다.

#### Scenario: 두 짧은 수업

- **WHEN** 같은 날 출석한 종료 수업이 40분씩 두 건 있다
- **THEN** 참여 횟수 2와 총 80분을 구분해 안내한다.

### Requirement: LEARN-003 개인 회고의 저장 범위

시스템 SHALL 회고를 프로필별 브라우저 localStorage 키에 저장하고 날짜별 최대 500자만 읽어들인다. 잘못된 저장 데이터는 빈 데이터로 처리한다. 서버 저장·기기 간 동기화·실제 AI 분석 기능으로 안내하지 않는다.

#### Scenario: 프로필 전환

- **WHEN** 같은 브라우저에서 다른 학생 프로필의 회고를 연다
- **THEN** 프로필별 키를 사용하고 다른 학생 회고를 현재 학생의 것으로 표시하지 않는다.
