# organization-settings Specification

## Purpose
조직의 새 클래스 기본값과 공통 예약 규칙을 구분하고 영역별 저장·입력 보존·동시 저장 동작을 정의한다. 설정 변경만으로 기존 클래스와 예약을 다시 작성하지 않는다.

## Requirements

### Requirement: SET-001 영역별 독립 저장

시스템 SHALL 클래스 기본값·예약 기간·예약 시간/마감·휴무 요일·취소 기한을 각각 저장하고 수강생 유형은 별도 저장한다. 선택 영역의 입력만 검증하며 다른 초안·오류·저장 상태를 유지한다. 알 수 없는 section이나 필수값 누락은 전체 저장으로 해석하지 않는다.

#### Scenario: 다른 영역의 잘못된 초안

- **WHEN** 취소 기한에 잘못된 미저장 값을 둔 상태에서 휴무 요일을 저장한다
- **THEN** 휴무 요일만 저장하고 취소 기한의 초안을 보존한다.

### Requirement: SET-002 최신 값 병합과 원자성

시스템 SHALL 같은 조직의 동시 영역 저장을 최신 저장값에 병합한다. 클래스 길이·정원과 시간 규칙·차단 시각은 각 영역 내부에서 함께 저장하거나 함께 실패해야 한다. 기존 통합 폼의 생략 필드는 기존 값을 유지한다.

#### Scenario: 동시 다른 영역 저장

- **WHEN** 두 관리자가 클래스 기본값과 예약 시간을 동시에 저장한다
- **THEN** 서로 다른 영역의 성공한 값을 덮어쓰지 않고 모두 보존한다.

### Requirement: SET-003 모바일 탭과 상태 보존

시스템 SHALL 768px 미만에서 선택 설정 탭 하나를 표시하고 탭 전환 중 입력·오류·저장 요청을 유지한다. 데스크톱은 전체 영역을 표시한다. 탭 이동은 URL 해시·페이지 위치 이동으로 구현하지 않는다.

#### Scenario: 저장 중 탭 이동

- **WHEN** 휴무 요일을 저장하는 도중 다른 탭으로 이동한다
- **THEN** 요청은 계속되고 응답이 현재 탭을 강제 변경하지 않는다.
