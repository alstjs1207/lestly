# Lestly

**수업에 집중할 수 있도록, 클래스 운영을 한곳에서.**

Lestly는 1인 강사와 소규모 클래스 운영자를 위한 수업 운영 서비스입니다.
클래스 소개부터 수강생 관리, 일정 예약, 출결 확인과 학습 기록까지 하나의 흐름으로 연결합니다.
운영자는 수업과 수강생 현황을 관리하고, 수강생은 직접 가능한 일정을 확인하고 예약할 수 있습니다.

## 이런 분들을 위해 만들었습니다

- 개인 레슨과 과외 일정을 직접 관리하는 강사
- 미술·뷰티·공예 등 소규모 클래스를 운영하는 운영자
- 여러 클래스와 강사의 일정을 함께 관리하는 교육 공간
- 수강생 명단, 예약과 출결을 한곳에 모으고 싶은 운영자

## 주요 기능

### 클래스 소개와 강사 관리

클래스별 소개, 커버 이미지, 담당 강사와 수업 정보를 관리합니다.
공개한 활성 클래스는 고유 링크로 공유할 수 있어 SNS 프로필이나 안내 메시지에서 수업을 소개하기 좋습니다.
대면·온라인 수업에 맞는 장소 안내와 강사 프로필도 함께 제공합니다.

### 수강생 관리

수강생의 연락처, 수강 기간과 이용 상태를 관리하고, 운영 방식에 맞게 수강생 유형을 설정할 수 있습니다.
명단 일괄 등록과 초대를 지원하며, 수강 종료·탈퇴·수강 재개 과정에서도 기존 수업 이력을 보존합니다.

### 예약과 일정 운영

수강생은 가능한 날짜와 시간을 확인하고 직접 예약하거나 허용된 기한 안에 취소할 수 있습니다.
운영자는 단건·주간 반복 일정을 등록하고, 특정 회차 또는 이후 회차의 일정을 변경·취소할 수 있습니다.
클래스별 수업 길이와 정원을 적용하고, 수강생의 중복 예약과 정원 초과를 방지합니다.

### 운영 방식에 맞는 예약 설정

예약 오픈 방식을 월별 또는 오늘 기준 일정 기간으로 선택할 수 있습니다.
예약 시작 시간과 간격, 접수 마감, 수강생 신청 차단 요일과 취소 기한을 설정합니다.
클래스별 수업 길이·정원과 조직 공통 예약 규칙을 구분해 관리합니다.

### 출결과 학습 기록

수업별 출석·결석을 확인하고 출결 변경 이력을 관리합니다.
수강생은 출석이 확인된 종료 수업을 기준으로 참여 횟수, 실제 학습 시간과 활동 히트맵을 확인할 수 있습니다.

### 예약 알림

예약 생성·변경·취소와 수업 리마인더를 위한 알림 기능을 제공합니다.
조직의 기능 활성화와 채널 설정에 따라 이메일·알림톡과 관리자·담당 강사의 기기 푸시를 사용합니다.

## 이용 흐름

1. **운영 준비** — 클래스와 강사를 등록하고 예약 규칙을 설정합니다.
2. **수업 소개** — 공개 클래스 링크로 수업을 안내합니다.
3. **수강생 등록** — 수강생 정보를 등록하고 초대합니다.
4. **일정 운영** — 수강생이 직접 예약하거나 운영자가 일정을 등록합니다.
5. **수업 기록** — 출결을 확인하고 수강생이 참여 내역과 학습 기록을 돌아봅니다.

## 운영 원칙과 현재 제공 범위

예약 날짜와 마감은 한국 시간(Asia/Seoul)을 기준으로 처리합니다.
예약 차단 설정은 설정 이후 새로 신청하는 수강생 예약부터 적용하며, 기존 예약은 유지합니다.
취소 기한은 예약 당시의 규칙을 보존해 이후 설정 변경으로 기존 예약의 조건이 바뀌지 않도록 합니다.

현재 클래스 상담 접수는 일시 중단 상태입니다.
실제 수강료 결제·환불, 회차권 차감과 수강생별 클래스 배정은 제공하지 않습니다.
