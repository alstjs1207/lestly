# 수강생 졸업과 학원 탈퇴 정책

상태: 제품 정책 · 2026-10-25

졸업은 수강 완료, 탈퇴는 학원 이용 종료를 뜻한다. 두 상태 모두 새 수업을 예약할 수 없다.

## 상태별 이용 범위

| 구분 | 재원 `NORMAL` | 졸업 `GRADUATE` | 탈퇴 `DELETED` |
| --- | --- | --- | --- |
| 의미 | 수강 중 | 수강 완료 | 중도 종료 또는 이용 종료 |
| 로그인 | 가능 | 가능 | 불가 |
| 신규 예약·초대 | 가능 | 불가 | 불가 |
| 학생의 수업 기록 조회 | 가능 | 가능 | 불가 |
| 관리자 명단 | 기본 목록 | 졸업 필터 | 탈퇴 필터 |
| 재원생 수 집계 | 포함 | 제외 | 제외 |

## 공통 처리 기준

1. **관리자가 직접 변경한다.** 수강 종료일이 지나도 자동으로 졸업·탈퇴 처리하지 않는다.
2. **남은 예약은 자동 취소한다.** 졸업·탈퇴 확인창에 취소될 예약 건수를 표시하고, 처리 시 해당 학원의 시작 전 예약을 모두 자동 취소한다. 예약 취소와 상태 변경은 함께 처리한다. 진행 중 수업은 종료 후 처리하며, 이미 끝난 수업 기록은 유지한다.
3. **수업 안내를 중단한다.** 졸업·탈퇴 후 해당 학원의 수업 알림과 초대를 중단한다.
4. **과거 기록은 상태 변경만으로 삭제하지 않는다.** 관리자는 기존 수업 이력을 확인할 수 있다. 개인정보 보유·삭제는 별도로 정한 개인정보 처리 기준을 따른다.
5. **다시 다니면 재원으로 변경한다.** 기존 학생 정보를 사용하고 수강 기간을 확인한다. 취소된 예약은 복구하지 않는다.
6. **탈퇴자는 로그인과 서비스 이용을 차단한다.** 탈퇴 처리 시 기존 로그인 세션도 종료한다. 졸업생은 로그인과 본인 수업 기록 조회가 가능하다. 탈퇴 처리와 계정·개인정보 삭제는 구분한다.

## 수강 종료일 이후

- 수강 기간은 한국 날짜 기준으로 종료일 당일까지 유효하다. 학생과 관리자 모두 수업 시작일이 수강 기간을 벗어나는 예약을 등록하거나 변경할 수 없다.
- **관리자의 단건 등록·일정 변경에도 동일하게 적용한다.** 수강 종료일 이후 날짜로 단건 예약을 등록하거나 기존 예약을 옮길 수 없다. 반복 예약의 생성·변경도 모든 회차가 수강 기간 안에 있어야 한다. 종료일 이후 수업이 필요하면 수강 기간을 먼저 연장한다.
- 종료일이 지난 재원생은 ‘수강 기간 만료’로 안내한다. 재원 상태와 로그인·수업 기록 조회는 유지하며, 자동으로 졸업·탈퇴 처리하지 않는다.
- **개별 수강생의 수강 종료일을 앞당기면 새 종료일 이후의 예정 예약을 자동 취소한다.** 수업 시작일을 한국 날짜로 비교하며, 단건·반복 예약 모두 적용한다. 변경 확인창에 취소될 예약 건수를 표시하고, 종료일 변경과 예약 취소는 함께 처리한다. 이미 끝난 수업 기록은 유지한다.
- 날짜가 지나 수강 기간이 만료되는 것만으로는 예약을 자동 취소하지 않는다. 종료일을 앞당기거나 졸업·탈퇴 처리할 때 위 기준에 따라 취소한다.
- 관리자가 수강 기간을 연장하면 재원생은 연장된 기간 내에서 다시 예약할 수 있다. 졸업·탈퇴자는 재원 상태로도 변경해야 한다.
