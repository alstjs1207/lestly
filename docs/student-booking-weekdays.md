# 수강생 신청 차단 요일

관리자 → 설정 → 일정 설정의 **수강생 신청 차단 요일**에서 휴무일을 선택하고
**설정 저장**을 누른다. 월요일부터 일요일까지 개별 선택할 수 있고, **주말 차단**과
**차단 해제**를 제공한다. 모든 요일을 선택하면 신규 예약이 모두 차단된다.

- 조직별 `settings.disabled_booking_weekdays`에 `{ "value": [6, 0] }` 형태로
  저장한다. 일요일은 0, 월요일은 1, 토요일은 6이다. 설정이 없거나 빈 배열이면
  모든 요일이 허용된다.
- 한국 시간의 수업 시작 요일을 기준으로 매주 적용한다. 기존 일정은 유지하며
  관리자의 직접 일정 등록·수정은 허용한다. 기존 정원·중복·수강 기간 검증은 유지한다.
- 수강생 주간 화면에 휴무일을 표시하고 예약 패널과 월별 목록의 예약 창에서
  신규 신청을 차단한다. 기존 예약은 계속 확인하고 관리할 수 있다.
- 최신 예약 가능 여부 응답에도 차단 요일을 포함한다. 화면을 열어 둔 사이
  설정이 바뀌어도 예약 RPC와 직접 INSERT는 DB 트리거가 최신 설정으로 검증한다.
- 기존 숫자·시간 설정과 요일 설정을 한 번의 upsert로 함께 저장한다.

## 배포

`0028_student_booking_weekdays.sql`은 설정 조회 정책과 두 기존 함수를 확장한다.
테이블의 업무 데이터나 실제 요일 설정은 변경하지 않는다. 신청 시간·출결·취소
필터를 포함한 0027의 기존 검증은 유지한다.

`node sql/operations/20261027_apply_booking_weekdays.mjs`는 읽기 전용 사전 검사다.
기존 이력과 함수 본문을 대조한다. `--apply`는 명시적으로 승인받은 DB 적용에만
사용한다. 트랜잭션 안에서 기존 함수 정의를 보존하고 마이그레이션을 적용한 뒤
업무 데이터의 행 해시와 함수 권한이 그대로인지 확인한다.

프리뷰와 운영은 Supabase 프로젝트 `smbpzlzbvplhtpqggrjf`를 공유한다. DB 적용과
프리뷰에서 저장한 실제 휴무 설정은 운영의 신규 예약에도 적용된다. 앱은
`preview` 브랜치에만 배포하며 운영 앱 배포는 별도다.
