# 수강생 학습 화면 개선 (2026-10-23)

확정한 시안을 `/dashboard`, `/learning-records`, `/my-schedules`, `/my-schedules/list`에 반영했다. 원본 저장소에서 작업했으며 별도 worktree나 clone은 만들지 않았다.

## 화면 구성

- 홈: 작은 오늘의 응원 → 인사 → 쌓여가는 배움 → 다음 수업 → 오늘의 한 줄. PC에서는 배움과 다음 수업·회고를 나란히 표시한다.
- 컨디션과 작은 실천 체크리스트는 사용자 요청대로 홈에서 제거했다. 근거 없는 AI 조언·목표 평가·월간 배지 표현도 사용하지 않는다.
- 배움 기록: 최근 12주 히트맵, 수업 이력 / 한 줄 회고 탭, 월 또는 전체 기간 필터. 수업 카드는 날짜·시작/종료·총 시간·수업명만 표시하고 상세 창에서 강사·장소를 보여준다. 좁은 PC와 태블릿에서도 카드를 사용한다.
- 모바일에서는 학습 홈 / 나의 일정 / 배움 기록 / 내 정보 하단 메뉴를 제공한다.

## 정보와 운영 기준

- 집계는 **종료된 수업 일정**에 대한 것이며 출석·실제 이수 확인이 아니다. 히트맵은 수업 시작일(한국 날짜)에 해당 수업의 전체 시간을 반영한다. 진행 중인 수업은 종료 후 반영된다.
- 현행 DB는 09:00~20:00 시작, 3·6·9시간 수업을 허용한다. 이를 임의로 바꾸지 않았으며, 자정을 넘기는 종료일도 예약 요약과 수업 상세에 표시한다.
- 강사와 장소는 프로그램의 실제 등록 정보를 사용한다. 준비물 전용 필드와 학원 문의 연락처는 현재 스키마에 없으므로 임의의 준비물이나 전화번호를 생성하지 않고 담당 강사에게 기존 연락 방법으로 문의하도록 안내한다.
- 회고는 계정별 브라우저 저장이다. 기기 간 동기화는 지원하지 않는다. 기존의 소유 계정·날짜를 알 수 없는 `coaching-reflection` 값은 자동으로 배정하거나 삭제하지 않는다.
